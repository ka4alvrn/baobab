# Nocturne — Кровь Империи

Русскоязычная интерактивная новелла для браузера и Telegram Mini App. Глава I «Обратная сторона листа» — один день из жизни петербургского архивиста Алексея Андреевича Вельского. Вся первая глава проходится за человека.

## Чтение

У каждой сцены есть место, дата и время. Дневник и архив персонажей раскрывают только прочитанное. У решений есть последствия; игра сохраняет сцену, позицию прокрутки, ход столкновения и открытия на этом устройстве. У новой редакции отдельный ключ сохранения (`nocturne:chapter-one-v3`): старая версия не смешивается с переписанным сюжетом и не удаляется.

Один полный маршрут содержит порядка 10–11 тысяч слов, без альтернативных сцен, интерфейса и дневника. Ориентир на час предполагает чтение около 180–200 слов в минуту с паузами на решения; принудительных задержек нет.

## Запуск и проверки

- `python3 -m http.server 8000 --bind 0.0.0.0` — запуск из корня проекта; открыть `/`.
- `node --test` — проход по графу решений, длина **каждого** полного маршрута, хронология, доступность иллюстраций, финалы и восстановление после боя.
- Для подключения к боту разместить статические файлы на HTTPS-хостинге и назначить URL кнопке меню. Сборка и ключи API не нужны.

`story.js` содержит все сцены (спойлеры). `engine.js` отвечает за переходы и сохранения, `app.js` — за интерфейс чтения и настройки. Иллюстрации созданы для проекта. Лицензия Cormorant Garamond: `assets/fonts/LICENSE`.
