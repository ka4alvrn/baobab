# Nocturne — Кровь Империи

Статическая русскоязычная интерактивная новелла. В этой версии доступны пролог и первая разветвлённая глава. Главное меню и режим чтения — отдельные экраны. Игра запоминает открытые записи архива, решения и ход столкновения на текущем устройстве. После гибели доступен возврат к контрольной точке. Сохранения из исходного пролога поддерживаются.

## Запуск

`python3 -m http.server 8000 --bind 0.0.0.0`

Откройте `/` в браузере. Для подключения как Telegram Mini App опубликуйте файлы на HTTPS-хостинге и назначьте URL кнопке меню бота. Сборка и API-ключи не требуются.

## Разработка

- `story.js` — текст, сцены, развилки и их условия (содержит спойлеры).
- `engine.js` — переходы, бой, контрольные точки и совместимость сохранений.
- `app.js` — отображение, история навигации, настройки и звук.
- `node --test` — автономная проверка достижимости сцен, исходов боя и переходов из старых сохранений.
