# Nocturne — Кровь Империи

Адаптивный главный экран русскоязычной готической новеллы и короткий интерактивный пролог. Статическое приложение без сборки и внешних зависимостей.

Локальный запуск: `python3 -m http.server 8000 --bind 0.0.0.0`. Для использования как Telegram Mini App разместите файлы на HTTPS-хостинге и назначьте адрес кнопке меню бота. Прогресс и размер текста хранятся в localStorage данного устройства. Атмосферный звук синтезируется после нажатия кнопки.

Иллюстрация создана для проекта. Шрифт Cormorant Garamond распространяется по SIL Open Font License (см. assets/fonts/LICENSE).
